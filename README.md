# FastAPI-калькулятор

Готовое учебное приложение на Python 3.10+ с четырьмя арифметическими операциями и вычислением сложных выражений с переменными.

## Запуск

Откройте терминал в папке проекта, где находится этот README. Установите Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируйте окружение в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Если запуск скриптов запрещён политикой системы, активация не обязательна: используйте `.venv\Scripts\python.exe` вместо `python` в следующих командах.

В macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимости и запустите сервер:

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000/docs — здесь можно выполнить любой запрос через **Try it out**. Описание API: http://127.0.0.1:8000/redoc, схема: http://127.0.0.1:8000/openapi.json. Остановка сервера: Ctrl+C. Режим `--reload` предназначен для разработки.

## Методы API

Все вычисления принимают JSON и возвращают `{"result": число}`. Простые операции используют поля `a` и `b`.

| Метод | Путь | Назначение | Пример тела | Результат |
|---|---|---|---|---|
| POST | `/add` | Сложение | `{"a":2,"b":3}` | `5.0` |
| POST | `/subtract` | Вычитание | `{"a":2,"b":3}` | `-1.0` |
| POST | `/multiply` | Умножение | `{"a":2,"b":3}` | `6.0` |
| POST | `/divide` | Деление | `{"a":7,"b":2}` | `3.5` |
| POST | `/calculate` | Операция по символу | `{"a":7,"op":"/","b":2}` | `3.5` |
| POST | `/evaluate` | Выражение с переменными | см. ниже | `22.0` |
| GET | `/` | Информация о приложении | — | ссылка на документацию |

### Сложное выражение

```json
{
  "expression": "(a+b)*c + (d-e)/(f-g)",
  "variables": {"a": 2, "b": 3, "c": 4, "d": 10, "e": 4, "f": 5, "g": 2}
}
```

Ответ:

```json
{"result": 22.0}
```

Допускаются целые и дробные числа, научная запись `2e3`, скобки, унарные `+` и `-`, операции `+ - * /`. Умножение и деление выполняются раньше сложения и вычитания; операции одного приоритета — слева направо. Дробный разделитель — точка. Умножение указывайте явно: `2*a`.

Имена переменных чувствительны к регистру, начинаются с латинской буквы или `_`, далее разрешены цифры; длина до 64 символов. Поле `variables` необязательно. Все использованные переменные должны быть заданы; неиспользованные допустимы.

Приложение реализует вариант задания с полной строкой выражения: вложенные подвыражения задаются скобками. Отдельное хранение текущего выражения и методы его просмотра/выполнения не требуются согласно условию задания. Каждый запрос независим.

### Примеры PowerShell

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/add -ContentType 'application/json' -Body '{"a":2,"b":3}'
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/evaluate -ContentType 'application/json' -Body '{"expression":"(a+b)*c + (d-e)/(f-g)","variables":{"a":2,"b":3,"c":4,"d":10,"e":4,"f":5,"g":2}}'
```

### Примеры curl (macOS / Linux / Git Bash)

```bash
curl -X POST http://127.0.0.1:8000/divide -H 'Content-Type: application/json' -d '{"a":7,"b":2}'
curl -X POST http://127.0.0.1:8000/evaluate -H 'Content-Type: application/json' -d '{"expression":"2+3*4"}'
```

Готовые запросы для расширения VS Code REST Client находятся в `examples/requests.http`.

## Ошибки и ограничения

- `400`: деление на ноль, неверный синтаксис, неизвестная переменная, запрещённая конструкция, превышение сложности, неконечный результат. Например, `1/0` возвращает `{"detail":"Деление на ноль запрещено"}`.
- `422`: неверная структура JSON, пропущенное поле, лишние поля, неподходящий тип или слишком длинная строка. Числовые строки и логические значения не принимаются как числа.
- Используется обход разрешённых узлов AST, без `eval`, `exec` и `ast.literal_eval`. Вызовы функций, атрибуты, индексация, коллекции, степени, остаток и целочисленное деление запрещены.
- Ограничения: 1000 символов, 256 узлов AST, глубина вычисления 32 и не более 100 переменных.
- Расчёты используют `float`, поэтому возможны обычные погрешности двоичной арифметики, например `0.1+0.2`. Приложение не предназначено для точных денежных расчётов.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Локально пройдены **54 теста** на Python 3.12.

Проверяются все операции, порядок вычислений, скобки, переменные, некорректные входные данные, деление на ноль, переполнение и попытки исполнения кода. Тесты API используют FastAPI TestClient и HTTPX по [официальной документации](https://fastapi.tiangolo.com/tutorial/testing/). GitHub Actions запускает их при push и pull request на Python 3.10–3.13.

## Публикация на GitHub

1. Распакуйте архив и откройте папку проекта. Создайте на GitHub пустой репозиторий `fastapi-calculator` с видимостью **Public**. Не добавляйте README автоматически.
2. Выполните в папке проекта (замените `YOUR_USERNAME` своим именем):

```bash
git init
git add .
git commit -m "Add FastAPI calculator with tests"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/fastapi-calculator.git
git push -u origin main
```

3. Авторизуйтесь в GitHub, если Git запросит вход. Проверьте зелёный статус вкладки **Actions** и откройте репозиторий в приватном окне браузера, чтобы убедиться в публичном доступе.
4. Для сдачи отправьте ссылку на репозиторий и при необходимости прямую ссылку на файл `app/main.py` через кнопку **Copy permalink** на странице файла GitHub.

Публикация исходников на GitHub не запускает сервер в интернете: для проверки преподаватель может клонировать репозиторий и выполнить инструкции запуска.
